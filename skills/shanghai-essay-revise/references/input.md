# 输入识别与疑点处理

支持粘贴文本、TXT/Markdown、DOCX、照片及PDF。提取文件时使用可用文档工具，不把排版标记或页眉当作文。

## 手写与扫描

1. 按页序转录题目和正文，保留段落、删改痕迹中的最终可辨读内容；不先润色再称作原文。
2. 用 `〔待确认：候选字/位置〕` 标记不确定内容。特别核对否定词、关联词、人名、引文和跨页顺序。
3. 一次列出影响解释和论证的疑点，请作者确认。可先批改无歧义部分，但不基于猜测改立意或输出伪装完整的定稿。
4. 识别清晰且无需确认时直接进入批改，在记录中写明“图片转录”；用户纠正后更新本轮转录，不把机器误读计为作者病句。

不推测无法看到的卷面质量，不替用户猜漏页。不默认向外部OCR服务上传原件；优先已配置的本地识别或直接视觉阅读。

## 缺少内容

- 缺题目：仅在实际看得到原文时做可支持的局部检查，询问题目以完成审题。原文也不可见时只索取输入，不编造诊断。
- 缺评分表：默认批改不受影响；用户请求评分时说明依据缺口。
- 只给段落：指出与全文有关的判断限制，完成局部任务。
- 未提供年级水平样本：保留当前原稿的好表达，不推断作者个人能力或稳定文风。
